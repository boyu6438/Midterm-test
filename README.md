會提醒你的智慧藥盒 (NUCLEO-G474RE 期中專題)
## 1. 情境故事：誰、在哪、遇到什麼麻煩
* **誰與在哪**：在家中需要每天服用慢性病藥物的長輩，以及在外工作的子女。
* **遇到什麼麻煩**：
  * 長輩記憶力退化，看著藥盒發呆，搞不清楚今天的藥到底吃了沒。
  * 害怕沒吃而重複補吃，造成劑量過高風險；或直接漏吃藥物。
## 2. 替身對照：故事裡的模組 → 板上替身
* **時間到點提醒**：Timer 模擬定時器 → 時間到達自動切換至提醒狀態。
* **聲光提醒指示**：紅燈亮起 + 蜂鳴器持續發聲 → 提醒長輩服藥。
* **按鈕確認機制**：長輩按下實體按鈕 (EXTI) → 停止蜂鳴器發聲、紅燈切換回綠燈（待機狀態）。
* **雲端/終端紀錄**：UART 傳送確認訊息 → 傳送服藥時間與確認紀錄至電腦終端機供記錄與追蹤。
## 3. 功能與驗收條件：動作、預期、實測結果
(1) 系統上電與初始待機 (IDLE)
動作：開發板程式燒錄完成後重新上電。
預期：綠燈(PC5)亮、紅燈(PC6)滅、蜂鳴器(PC8)靜音，並啟動 10 秒計時。
實測結果：綠燈正常點亮、紅燈熄滅、蜂鳴器無聲，10 秒計時順利啟動。
(2) 定時提醒與警報觸發 (ALERT)
動作：系統維持運行並等待滿 10 秒。
預期：切換至 ALERT 狀態，綠燈(PC5)熄滅、紅燈(PC6)點亮、蜂鳴器(PC8)發出 PWM 警報聲。
實測結果：滿 10 秒後，燈號正確切換且蜂鳴器順利發出聲響。
(3) 按鈕確認與解除警報
動作：警報響起時，按下連接於 PC9 的按鈕（或以杜邦線瞬間觸發至 GND）。
預期：觸發外部中斷(EXTI9)，蜂鳴器停止發聲、紅燈(PC6)滅、綠燈(PC5)重新亮起，系統回待機狀態並重置 10 秒計時。
實測結果：按下按鈕後，蜂鳴器即刻停止，燈號與計時皆成功重置。
## 4. 用到的技術：第 3～7 週勾選表
**GPIO**：控制 LED 狀態燈號（綠燈=待機；紅燈=提醒中）與讀取按鈕輸入狀態。
**EXTI / NVIC**：按鈕中斷處理，快速回應使用者的確認操作並切換狀態。
**Timer**：計算設定時間，時間到點觸發提醒狀態。
**PWM**：控制蜂鳴器發聲方式
## 5. 腳位表：用到的每支腳與用途
PC5 腳位：連接綠燈（Green LED），設定為推挽輸出模式（GPIO_MODE_OUTPUT_PP）。其用途是在系統處於待機狀態（IDLE）時點亮，表示系統運作正常。
PC6 腳位：連接紅燈（Red LED），設定為推挽輸出模式（GPIO_MODE_OUTPUT_PP）。其用途是在系統進入提醒狀態（ALERT）時點亮，用以警示使用者。
PC8 腳位：連接蜂鳴器（Buzzer），設定為 PWM 輸出模式（TIM3_CH3）。其用途是在時間到達 10 秒觸發警報時，透過 PWM 輸出聲音提示。
PC9 腳位：連接確認按鈕（Button），設定為外部中斷下降緣觸發模式（GPIO_MODE_IT_FALLING）並啟用內部上拉（GPIO_PULLUP）。其用途是用戶按下按鈕時觸發中斷，用來停止警報、切回待機狀態並重置計時。
## 6. 建置與執行：開發環境、燒錄步驟、終端機設定、命令
開發環境：STM32CubeIDE、STM32G474RE 開發板。
建置與編譯：確認 Assembly 搜尋路徑包含 Core/Inc 與 HAL 庫，執行 Clean 與 Build 確保 0 錯誤。
燒錄步驟：透過 ST-LINK 連接開發板，於 IDE 中點擊 Run 燒錄。
執行說明：已移除 UART，完全透過硬體燈號、蜂鳴器與按鈕進行互動。
## 7. 程式結構：哪個檔做什麼、ISR 與主迴圈分工
主要檔案與職責：
main.c：核心程式邏輯所在，包含系統初始化、狀態機切換（IDLE/ALERT）、周邊設定（GPIO 與 TIM3 PWM）以及按鈕外部中斷回呼函式。
main.h：存放專案共用的標頭檔引入、常數與腳位巨集定義。
startup_stm32g474retx.s：晶片啟動組合語言檔案，負責硬體重置向量設定並跳轉進入 main() 函式。
ISR 與主迴圈分工：
中斷服務常式 (ISR / HAL_GPIO_EXTI_Callback)：專責處理外部硬體觸發（PC2 按鈕）。當按鈕按下時執行防彈跳機制，並迅速將觸發旗標 buttonPressed 設為 1，確保 ISR 保持極簡高效。
主迴圈 while(1)：負責系統狀態機的邏輯運作，透過 HAL_GetTick() 實現非阻塞式時間監控：
待機狀態 (IDLE)：持續計算時間，若滿 10 秒則自動切換至 ALERT 狀態，點亮紅燈、熄滅綠燈並啟動蜂鳴器 PWM。
提醒狀態 (ALERT)：持續輪詢檢查 buttonPressed 旗標；一旦偵測到為 1，即刻關閉蜂鳴器、恢復綠燈、重置 10 秒計時並切回 IDLE 狀態。
